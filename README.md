# 메가주 2026 시즌2 · 부스 & 이벤트 & 동선 가이드

2026 메가주 일산 시즌2(2026.11.20~22, 킨텍스 제1전시장 2~5홀) 현장에서 폰으로 바로 쓰는 가이드입니다.

- **부스 탭**: 692개 부스 / 711개 참가브랜드 검색, 홀·카테고리·이벤트 필터
- **이벤트 탭**: 주최측이 공개한 참가브랜드 현장이벤트(선착순·쿠폰·뽑기·할인 등)를 부스별로 정리
- **내 코스 탭**: ☆로 담은 부스를 **가로 훑기 동선**으로 자동 정렬 · 입구 반대쪽(안쪽) 가로 줄에서 시작해 입구 쪽 줄로 내려오면서, 한 줄은 왼쪽→오른쪽, 다음 줄은 오른쪽→왼쪽으로 번갈아 훑습니다(2·3·4홀 입구는 2홀 쪽 끝에서, 5홀 입구는 5홀 쪽 끝에서 시작) · 정시 이벤트 시각 고정, 오픈런은 개장 시각에 먼저 · 방문 체크, 공유 링크
- **핵심 코스 프리셋**: 「🎯 재현 핵심 코스」 버튼 한 번으로 핵심 8개 항목 9개 부스(눈영양제 5347 · 방수리드줄 3136 · 우신 간식 2122 멍멍하누·2542 오래오래프로젝트 · 목우촌 멍수무강 5601 · 유산균 3106 · 오메가3 5732 · XXL 옷 5316 · 트래킹 하네스 2331 테일하이) 10개 부스를 즐겨찾기에 담고 바로 추천 순서를 볼 수 있습니다. 그 아래 '더 볼 곳' 줄에 품목별 추가 후보(눈영양제 2457·2411·4501, 방수리드줄 5713·3338·5111, 유산균 5631·5417·4524, 오메가3 5214·3454, XXL 옷 2231·2505·5251, 우신 2544·4506·3552·5553·4357)를 적어 두었습니다. '우신'은 브랜드가 아니라 소의 말린 간식(불리스틱) 이름이며, 우신라보타치(라보타치 5523)는 영양제 회사라 핵심에서 뺐습니다
- **가격 탭**: 핵심 품목 **가격 21행**의 **공식몰·네이버 스마트스토어·자사몰 가격**과 **확인된 인터넷 최저가**를 나란히 정리(2026.11.17 재조회). 행마다 판매처 URL·옵션/수량·배송비·쿠폰/구독 조건을 적었고, 같은 상품이라도 구매 조건이 다르면 행을 나눴습니다(1개 단품 / 2개 묶음 / 정기구독·정기배송 / 150ml·300ml). “최저가”는 배송비까지 더한 직접 확인 구매가능가 기준이고, 쿠팡·오픈마켓 가격추적 사이트 값은 “관측가(변동 가능)”, 2월처럼 오래된 값은 “과거 관측 · 현재 최저가 미확인”으로 구분해 표시합니다. 맨 위에 현장 비교 체크리스트 5단계, 부스 카드에도 같은 가격·링크가 붙습니다
- **배치도 탭**: 주최측 공식 부스배치도(홀별 확대), 내 코스 동선 선 표시
- 즐겨찾기·방문 체크는 브라우저(localStorage)에 저장됩니다.
