# 메가주 2026 시즌2 · 부스 & 이벤트 & 동선 가이드

2026 메가주 일산 시즌2(2026.11.20~22, 킨텍스 제1전시장 2~5홀) 현장에서 폰으로 바로 쓰는 가이드입니다.

- **부스 탭**: 692개 부스 / 711개 참가브랜드 검색, 홀·카테고리·이벤트 필터

- **내 코스 탭**: ☆로 담은 부스를 **가로 훑기 동선**으로 자동 정렬 · 입구 반대쪽(안쪽) 가로 줄에서 시작해 입구 쪽 줄로 내려오면서, 한 줄은 왼쪽→오른쪽, 다음 줄은 오른쪽→왼쪽으로 번갈아 훑습니다(2·3·4홀 입구는 2홀 쪽 끝에서, 5홀 입구는 5홀 쪽 끝에서 시작) · 정시 이벤트 시각 고정, 오픈런은 개장 시각에 먼저 · 방문 체크, 공유 링크
- **핵심 코스 프리셋**: 「🎯 재현 핵심 코스」 버튼 한 번으로 핵심 13개 부스를 즐겨찾기에 담고 바로 추천 순서를 볼 수 있습니다 — 눈영양제 5347 바이오핏 · 방수리드줄 3136 와우펫 · 우신 간식 2122 멍멍하누·2542 오래오래프로젝트 · 목우촌 멍수무강 5601 · 유산균 3106 드시모네펫 · 오메가3 5732 에코-펫 · XXL 옷 5316 큰강아지 · 트래킹 하네스 2331 테일하이 · **유모차 가방 5607 이비야야 FP0032 · 온열 매트·패드 2310 시리어스펫 따땃패드 · 온열·탄소매트 3241 한일의료기 보듬 · 온열·냉방 매트 G-03 개판**(뒤 4곳은 2026-11-18 추가). 유모차 가방·온열 4곳은 부스 카드와 내 코스 순서에 ✅ **현장 확인 포인트**를 같이 적었습니다(FP0032 현장 판매·실물 확인, 따땃패드는 근적외선 찜질패드라 장시간 깔고 쓰는 온열방석과 용도가 다르다는 점과 설명서·수의사 상담 우선, 보듬·개판은 USB 보조배터리형 여부와 매트 크기·온도·자동차단 확인). 그 아래 '더 볼 곳' 줄에 품목별 추가 후보(눈영양제 2457·2411·4501, 방수리드줄 5713·3338·5111, 유산균 5631·5417·4524, 오메가3 5214·3454, XXL 옷 2231·2505·5251, 우신 2544·4506·3552·5553·4357, 유모차 방석·매트 2306·3254·2211)를 적어 두었습니다. '우신'은 브랜드가 아니라 소의 말린 간식(불리스틱) 이름이며, 우신라보타치(라보타치 5523)는 영양제 회사라 핵심에서 뺐습니다
