# 메가주 2026 시즌2 · 부스 & 이벤트 & 동선 가이드

2026 메가주 일산 시즌2(2026.11.20~22, 킨텍스 제1전시장 2~5홀) 현장에서 폰으로 바로 쓰는 가이드입니다.

- **부스 탭**: 692개 부스 / 711개 참가브랜드 검색, 홀·카테고리·이벤트 필터
- **이벤트 탭**: 주최측이 공개한 참가브랜드 현장이벤트(선착순·쿠폰·뽑기·할인 등)를 부스별로 정리
- **내 코스 탭**: ☆로 담은 부스를 도면 좌표 기준 최적 순서(오픈런·선착순 우선 → 2홀→3홀→4홀→5홀)로 자동 정렬, 방문 체크, 공유 링크
- **배치도 탭**: 주최측 공식 부스배치도(홀별 확대)
- 즐겨찾기·방문 체크는 브라우저(localStorage)에 저장됩니다.
