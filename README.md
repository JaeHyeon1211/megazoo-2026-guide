## 거리·시간 환산 근거 (2026-11-19 재계산)

화면의 이동거리·도착시각은 부스 좌표를 **도면 직선거리**로 환산한 참고치입니다. 통로를 실제로 도는 경로를 계산한 값이 아니고, 대기줄·구매 시간은 들어 있지 않습니다. 아래 숫자만으로 같은 값을 다시 계산할 수 있습니다.

| 단계 | 값 | 계산 |
| --- | --- | --- |
| 1. 도면 | 배치도 PDF(2026.11.17) 1페이지 = **3,215.29 × 2,267.72pt** | 부스 좌표는 이 페이지를 가로·세로 각각 0~1,000으로 나눈 값 |
| 2. 좌표 1단위의 pt 길이 | x 1단위 = 3.2153pt · y 1단위 = 2.2677pt | 3,215.29/1,000 · 2,267.72/1,000 |
| 3. 도면 영역 | 전시장 영역(회색 바탕) = **3,115.0 × 2,032.4pt** | 킨텍스 공식 시설개요의 제1전시장 2~5홀 = 홀당 63m × 171m, 4홀 나란히 = **252m × 171m** |
| 4. 축별 축적 | 가로 0.08090 m/pt · 세로 0.08414 m/pt | 252/3,115.0 · 171/2,032.4 |
| 5. 검산① | 표준 1부스 칸 폭 37.1pt → **3.00m** | 37.1 × 0.08090 (킨텍스의 3m×3m 부스 기준과 일치) |
| 6. 검산② | 2홀 출입구(108.8) ~ 5홀 출입구(844.7) = 735.9단위 → **191m** | 735.9 × 3.2153 × 0.08090 (홀 3개 폭 189m와 1% 차) |
| 7. 결론 | x 1단위 = **0.260m**(도면 1,000 ≈ 260m) · y 1단위 = 0.191m | 3.2153 × 0.08090 · 2.2677 × 0.08414 |
| 8. 세로 보정 | dist = √(Δx² + (0.7335·Δy)²) | 0.191 / 0.260 (페이지 가로:세로 비만 쓰면 0.7053) |
| 9. 시간 | 통로 보행 **50m/분** 가정 + 부스당 체류 2~10분 | 거리/50 + 체류 (대기·구매시간 미포함) |

- 이전 판의 「1,000 ≈ 166m / 세로 0.75」는 위 계산으로 재현되지 않아 바로잡았습니다(166m는 홀 길이 171m를 가로축에 맞춘 값으로 보이며, 그 경우 홀 폭·부스 폭 검산과 맞지 않습니다). 같은 좌표로 계산한 거리는 이전 표기의 약 1.57배가 됩니다.
